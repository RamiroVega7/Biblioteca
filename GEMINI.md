# Reglas del Proyecto Biblioteca

- **Lenguaje principal:** Visual Basic .NET (`VB.NET`).
- **Framework:** .NET (WPF / Windows Presentation Foundation).
- **Arquitectura:** Arquitectura en capas estricta:
  - **UI (User Interface):** Formularios, ventanas XAML y ViewModels.
  - **BLL (Business Logic Layer):** Reglas de negocio y orquestación.
  - **DAL (Data Access Layer):** Acceso a datos SQLite y consultas parametrizadas.
  - **BE (Business Entities):** Modelos de dominio (`Models/`).
- **Instrucción estricta:** Todo el código nuevo o las modificaciones que se realicen en este proyecto deben escribirse exclusivamente en **Visual Basic** (`.vb`). No usar C# ni otros lenguajes a menos que el usuario lo solicite explícitamente.
- **Contexto completo:** Consultar `CONTEXT.md` para detalles de esquema, componentes y convenciones técnicas.
